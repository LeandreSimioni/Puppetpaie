Le code sur GitHub

PuppetPaie est un logiciel de paie gratuit, conçu pour que les compagnies de spectacle vivant puissent consacrer le plus d’argent possible à rémunérer les personnes.

Il est pensé de manière simple et collaborative : si vous trouvez des choses que vous auriez aimé voir, si vous avez des idées ou si vous rencontrez des problèmes, un petit formulaire vous permet de me faire vos retours et d’améliorer le logiciel pour tout le monde.

Le logiciel est léger, rapide et souverain. Tout se passe sur votre machine et dans vos mails.

L’import de votre compagnie est simple : munissez-vous de tous vos bulletins de paie pour récupérer votre historique directement dans le logiciel, et d’une DSN pour accélérer sa configuration. C’est parti !

Vous pouvez essayer le logiciel sur des compagnies fictives, pour le prendre en main ou simplement pour vous rassurer sur la manière dont les paies se font dans le spectacle vivant.
